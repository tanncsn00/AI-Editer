Khi user nói "idea ấy bạn" / "chọn idea đi" / "pick idea" → có nghĩa là **GỬI LIST CHO USER CHỌN**, không phải bảo mình tự quyết.

**Why:** User muốn quyền quyết định cuối, nhất là về content idea (vì hiểu audience hơn mình). Tự pick rồi chạy = mất thời gian nếu user không thích.

**How to apply:**
- List ít nhất 5-10 idea với hook draft + viral score + 1 dòng tóm tắt
- Sort theo viral potential mình đánh giá
- Mark recommend top 3 nhưng KHÔNG bắn pipeline
- Đợi user gõ số/tên → mới chạy GATE 1+2+3
- Áp dụng cho mọi creative work: video idea, hook variant, format choice, persona pick

Ngoại lệ: user explicit nói "tự chọn đi mình tin bạn" hoặc "decide for me" → mới được pick.
