**Rule:** Mass-appeal video target audience non-dev (founder/SME/student/knowledge worker) phải Việt hóa heavy. KHÔNG dùng English phrase ngoại trừ:
- Tech acronym dev quen: MCP, API, JSON, NPM, PDF, CSV, AI (đọc "ây ai")
- Tool name brand: Claude, GitHub, Tiki, Shopee, Telegram, etc
- Code snippet trong demo box (visual ok English)

**KHÔNG dùng English cho:**
- Soft skill concept: empathy → đồng cảm, taste → gu thẩm mỹ
- Action verb: "frame problem" → "đặt vấn đề", "resolve conflict" → "giải quyết mâu thuẫn"
- Business concept: leadership → lãnh đạo, polymath → người đa tài
- Workflow term: pattern match → ráp khuôn, novel synthesis → kết hợp mới mẻ
- Phrase mass-appeal: "in-person trust" → "tin tưởng qua gặp mặt"
